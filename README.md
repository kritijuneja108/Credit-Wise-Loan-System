#CreditWise-Loan-System<br>
Built an end-to-end supervised ML pipeline using KNN, Logistic regression, and Naive Bayes to predict loan approval. Implemented binary classification along with Exploratory Data Analysis(EDA), feature engineering, and model evaluation (Precision, Recall, F1).<br>
It is an intelligent loan approval system which is powered by machine learning that can automatically analyze applicant details and predict whether a loan should be approved or rejected before the final human verification.<br>
This system effectively tries to remove the two major challenges:<br>
1. Good customers sometimes get rejected, leading to loss of the business.<br>
2. High - risk customers sometimes get approved, leading to financial losses.<br>
